# Niko 0.2.3: apps fixados no dock, OpenCode v2 e base para Linux

Uma atualização com duas sugestões da comunidade para o dock, o plugin do OpenCode funcionando na v2 e uma organização por dentro que abre caminho para o Niko no Linux.

## Novidades

- Fixe apps no dock pelo botão direito em um app aberto. Eles ficam no dock mesmo fechados e abrem com um clique.
- Tamanho do dock de 70% a 120%, pelo menu do dock ou pelos Ajustes. No modo fixo, o espaço reservado na tela acompanha o tamanho.
- Primeira base do Niko para Linux (Fedora e Ubuntu com GNOME), a partir da contribuição do PR #11. Ainda não há instalador oficial para Linux. Quem quiser testar pode compilar seguindo o README-linux.md.

## Melhorias

- Cada versão na página de novidades vira uma gaveta, com a quantidade de mudanças, e a versão atual abre direto pelo aviso de novidades.
- O cartão do criador fica no topo da página de Atualização.
- Na ilha compacta, o personagem só se mexe quando está pensando ou escrevendo.
- Perguntas longas do Claude Code na ilha rolam sem esconder os botões de responder.
- Tudo o que depende do sistema foi reorganizado num só lugar, com verificação automática no Windows e no Linux a cada mudança.

## Correções

- O plugin do OpenCode funciona no OpenCode v2 e continua funcionando na v1. Quem já instalou vê a opção de atualizar na engrenagem da aba Código.
- O AtalhoTouch aparecia, piscava e sumia ao ser ligado no app instalado. Uma janela relia dados antigos logo depois de outra salvar e desfazia a mudança.

## Antes de instalar

- Esta release traz instaladores só para Windows.
- Um aviso de aplicativo não reconhecido pelo SmartScreen não é o mesmo que uma detecção de ameaça pelo Defender. Mantenha o antivírus ativo e baixe somente das releases oficiais.
